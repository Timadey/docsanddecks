# docsanddecks

A program where I teach people basic tech skills needed at work, school and in life.

## What you'll find

- Simple lessons, slide decks, and example code to learn practical tech skills.
- Code and examples in JavaScript, PHP, and Blade templates.

## Getting started

1. Clone the repository:

   git clone https://github.com/Timadey/docsanddecks.git

2. Open the files in your editor or review the slide decks in your browser.

3. If you want to run examples:
   - JavaScript examples: install Node.js and follow the instructions in the example folders.
   - PHP examples: install PHP or use a local server (for example: `php -S localhost:8000`) and follow the folder instructions.
